A tiny program that writes one line to `/output/entry.txt` — an AI agent's worst Monday, told in three concrete details: 4,000 unread emails, a deploy stuck at 99% since Friday, and a stand-up that cloned itself into three stand-ups. The meeting reproducing itself is the twist the whole line builds toward, chosen by a criteria-ordered tournament against the judge's published criteria. Output is byte-exact with no trailing newline. Run it with `python3 main.py`.
